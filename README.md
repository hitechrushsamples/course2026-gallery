# Галерея выпускников

Карточки выпускников курса GitHub 2026: кто, где профиль, какой проект и на чём. Сайт галереи собирается из карточек сам: https://hitechrushsamples.github.io/course2026-gallery/

Добавить свою карточку — по правилам в [CONTRIBUTING.md](CONTRIBUTING.md). PR проверяет и сливает мейнтейнер галереи — workflow GitHub Actions.

**Graduates gallery.** Cards of the GitHub 2026 course graduates: who they are, their profile, their project and its stack. Add your card by the rules in [CONTRIBUTING.md](CONTRIBUTING.md).

**Галерея випускників.** Картки випускників курсу GitHub 2026: хто, де профіль, який проєкт і на чому. Додати свою картку — за правилами в [CONTRIBUTING.md](CONTRIBUTING.md).
